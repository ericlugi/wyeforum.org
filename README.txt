WORLD YOUNG ECONOMISTS FORUM — WEBSITE
=======================================

This folder is the complete website. Keep all the files together in one
folder; the pages link to each other by filename, so the navigation only
works while they sit side by side.

PAGES
-----
  index.html .............................. Home
  events.html ............................. Work & Sessions
  speakers.html ........................... Collaborators
  team.html ............................... Team
  about.html .............................. About (founder's note + contact)
  event-global-macro-chinese.html ......... No. 01  Dr. Jinliang Li session
  event-case-study-development.html ....... No. 02  Case Study
  event-german-chinese-business.html ...... No. 03  Mr. Zhiyan Wei session
  event-inflation-research.html ........... No. 04  Inflation research

  index.html is the homepage. Most web hosts open it automatically.

PREVIEW BEFORE PUBLISHING
-------------------------
  Double-click index.html to open it in a web browser, then use the top
  menu (Home / Work & Sessions / Collaborators / Team / About) to move
  between pages.

PUBLISH IT (any one of these)
-----------------------------
  * Easiest: drag this whole folder onto  https://app.netlify.com/drop
    for a free live site in seconds.
  * Or upload every file into your host's public folder (often called
    public_html or www) using its file manager or FTP.
  * Or use GitHub Pages.

ABOUT THE IMAGES AND FONTS
--------------------------
  * Every photo of a person (team, collaborators, session photos) is built
    directly into the page files, so those always appear.
  * The large decorative header photos load from Unsplash (free stock photos,
    Unsplash License: free for commercial use, no attribution required), and
    the typefaces load from Google Fonts. Both load automatically whenever the
    device viewing the site is online, which a published website always is.
    If you would rather have the decorative photos saved inside this folder,
    just ask and they can be bundled in.
